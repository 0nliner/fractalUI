# UX-закон плотных приложений

Продукты, на которые распространяется: **imprint** (обучение + соцсеть),
**game_heart** (AI-генерация игрового контента), **fractal_cad** (CAD-редактор).
Общее у них — десктопный инструмент, где пользователь проводит часы и работает с
плотным содержимым: деревом объектов, канвасом, лентой, доской задач.

**Правило номер ноль: рабочая область священна.** Контент занимает максимум
площади. Хром (навигация, шапки, панели) — тонкий, а по возможности вызывается
по требованию и рисуется поверх, а не отжимает контент.

---

## 1. Экономия пространства

Это главное, чем «наш» интерфейс отличается от обычного дашборда с широким
сайдбаром. По убыванию важности:

1. **Навигация — рейл 48 px, только иконки.** Никаких раскрывающихся сайдбаров
   на 200+ px. Подписи живут в тултипах. Компонент: `NavRail`.
2. **Разделы раскрываются якорным флайаутом**, а не расширением рейла:
   панель ~256 px рядом с кнопкой, с заголовком, одной строкой описания и
   списком пунктов (иконка + подпись + мелкое описание + бейдж). Компонент:
   `NavFlyout`. Рейл при этом не меняет ширину — **контент не перекомпоновывается
   никогда**.
3. **Шапка тонкая — 44 px**: бренд слева, триггер командной палитры (⌘K) в
   центре, справа компактные чипы и иконки 13–14 px. Крупных кнопок с текстом в
   шапке нет. Компонент: `AppShell`.
4. **Мелкая типографика — норма**: 11 px вторичный текст и чипы, 10 px легенды и
   бейджи, 12–13 px основной. Иконки: 12–14 в шапке, 16–18 в рейле, 13–16 в
   списках.
5. **Панели плавают поверх, а не сжимают контент.** Сжимает только то, что
   пользователь сам ресайзит (док ассистента).
6. **Тумблер вместо экрана.** Если состояние можно показать сегмент-табом в той
   же области — не заводить отдельную страницу.
7. Скроллбары 7 px, трек прозрачный.

Шкала плотности (нарушать без причины нельзя):

| Элемент | Размер |
|---|---|
| рейл | 48 px, кнопка 40×40, иконка 16–18 |
| шапка | 44 px, иконка 13–14, padding 6 |
| флайаут | 256 px |
| строка списка | 28–36 px |
| бейдж-счётчик | 14×14, шрифт 9, `99+` при переполнении |

## 2. Карта регионов

| Регион | Отвечает за |
|---|---|
| Шапка | глобальное: бренд, поиск ⌘K, статусные чипы, оповещения, ассистент |
| Рейл | «куда пойти»: аватар сверху, разделы, внизу настройки/выход |
| Флайаут | пункты раздела, по требованию |
| Рабочая область | контент: мастер-страница из блоков на 12-колоночной сетке |
| Правый док | мета, ассистент; ресайзимый и **постоянно смонтированный** (генерация не должна обрываться при закрытии) |
| У курсора | фидбек внутри жеста: ввод значения, попап создания |

Дерево решений для новой фичи:
- Раздел приложения → иконка в рейле + флайаут.
- Действие над выбранным → контекстный тулбар/меню + хоткей.
- Свойство выбранного → правая панель.
- Отдельное состояние работы → **режим**: своя раскладка, остальное приглушено,
  выход по Esc, бейдж активного режима.
- Фидбек во время жеста → у курсора, НЕ в панели (глаза пользователя там).
- **Никогда: модалка поверх рабочей области.** Исключение — подтверждение
  необратимого удаления, и то предпочтителен in-place-конфирм.

| Компонент | Зачем |
|---|---|

копируй в приложение.

## 4. Метод макетов: wireframe-болванки

Так рисуются макеты новых экранов на обсуждение. **Макет не должен выглядеть
готовым продуктом** — иначе ревью уходит в шрифты и формулировки вместо
структуры.

**Правило: в макете нет работающих элементов.** Ни настоящих `input`/`select`,
ни реального контента, ни живых кнопок. Только болванки: `Bar` (строка текста),
`Av` (аватар), `Btn` (кнопка, `accent` для CTA), `WireStack` (абзац), `Field`
(поле ввода), `Shimmer` (загрузка).

Реальным текстом пишутся **только** названия блоков, их описания и подписи
навигации.

**Блок** (`Block`) — пунктирная рамка, номер в акцентном квадрате, название и
описание «зачем блок и на что референс». Номера нужны, чтобы на них ссылались в
обсуждении. Мастер-страница = `MasterGrid` (12 колонок) + блоки со `span(n)`.

**Обязательные тумблеры** (`DesignGallery` даёт их из коробки):
«Аннотации» — скрыть описания и увидеть чистую структуру; «Скелетоны» — все
блоки в состоянии загрузки. Плюс легенда: пунктир = болванка, акцент = CTA.

Макет показывается **внутри реального шелла** (рейл + шапка), чтобы сразу была
видна фактическая площадь контента.

## 5. Инварианты взаимодействия

- **Превью → коммит.** Операция показывает ghost/live-превью; коммит один, на
  mouse-up/Enter. Эфемерное состояние не пишется в историю/лог операций.
- **Ввод значений в любой момент жеста**: начал печатать во время драга — ввод
  перехватывает управление. Enter — коммит, Esc — отмена.
- **Esc — отмена строго по стеку**: ввод → жест → инструмент → снятие выбора →
  выход из режима. Один Esc — один уровень.
- **Локальный Esc** (в поповере, композере, флайауте) — слушать в **capture-фазе**
  со `stopImmediatePropagation()`: глобальный обработчик приложения обычно
  зарегистрирован раньше и иначе съест событие.
- **Хоткеи по `e.code`, не `e.key`** — иначе русская раскладка ломает всё
  (`Ctrl+Z` даёт `e.key === 'я'`). Гасить при фокусе в input/textarea/
  contenteditable, кроме undo/redo.
- **Владение клавиатурой у режима**: активный режим (скетч, размещение,
  открытое меню) обрабатывает клавиши первым и делает ранний `return`.
- Долгая операция → спиннер **поверх старого состояния** и **per-row busy**
  (блокируется только затронутая строка, не вся доска).
- N действий над мультивыбором = **один batch-запрос**, один шаг undo.
- Мягкий снэппинг к сетке/круглым значениям, `Alt` временно отключает.

## 6. Визуальная семантика

| Состояние | Стиль |
|---|---|
| hover | лёгкая подсветка поверхности |
| selected / active | акцентный цвет + фон акцента с малой альфой |
| ghost add / remove | полупрозрачный акцентный / danger |
| invalid | danger + курсор `not-allowed` |
| протухшая ссылка | пунктир или warning-бейдж, **не** сплошной красный на сцене |
| вне активного режима | приглушение остального |

Иконки — **один набор** (lucide), не смешивать библиотеки. Цвета — **только из
токенов** (`vars.color.*` / CSS-переменные темы); хардкод hex запрещён,
исключение — литералы в canvas/WebGL, где переменные недоступны.

## 7. Анти-паттерны (ревью заворачивает без обсуждения)

- Раскрывающийся сайдбар шире 48 px как основная навигация.
- Модалка / `window.confirm` / `alert` поверх рабочего потока.
- Панель, меняющая размер рабочей области при смене контекста.
- Вложенные контекстные меню глубже одного уровня.
- Иконка без тултипа; инструмент без хоткея.
- Кнопка на каждую фичу вместо контекстного появления действия.
- Операция без превью там, где превью уместно.
- **Макет с работающими элементами вместо болванок.**
- Крупная типографика в хроме; эмодзи вместо иконок; хардкод hex.
- Живые тяжёлые вьюпорты (3D/видео) в карточках списка — только статические
  превью; живой вьюпорт один, в деталке.
- Блокирующий весь UI на время запроса; N мутаций вместо batch.
- Копия `NavRail`/`AppShell`/wireframe-кита внутри приложения вместо импорта.
