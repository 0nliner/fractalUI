# @fractalui/icons

The icon set for the kit — a foundational package the components draw from.

```bash
npm i @fractalui/icons
```

Icons are consumed by `@fractalui/primitives` and `@fractalui/patterns` (e.g. the `AppShell` nav rail). You can also bring your own icon components anywhere the kit takes an `icon` prop — the kit does not force its icon set on you.

!!! note
    This package is a foundational layer; its public surface is intentionally minimal and grows alongside the components that use it.
