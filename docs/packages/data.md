# @fractalui/data

Shared data utilities used by the config-driven [`@fractalui/runtime`](runtime.md) — helpers for shaping the rows and datasets that screens render.

```bash
npm i @fractalui/data
```

!!! note
    This is a foundational layer with a deliberately small surface; it grows alongside `@fractalui/runtime`. If you're building screens by hand with `primitives`/`patterns`, you usually won't need it directly.
