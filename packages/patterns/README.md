# @fractalui/patterns

Составные UI-паттерны, лейауты и app-shell поверх @fractalui/primitives.

Часть набора **fractalUI** — слоистой headless UI-библиотеки для быстрой сборки веб-интерфейсов.

## Установка

```bash
npm i @fractalui/patterns
```
