# @fractalui/tokens

Дизайн-токены (vanilla-extract) для набора fractalUI.

Часть набора **fractalUI** — слоистой headless UI-библиотеки для быстрой сборки веб-интерфейсов.

## Установка

```bash
npm i @fractalui/tokens
```
