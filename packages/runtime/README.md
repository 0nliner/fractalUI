# @fractalui/runtime

Config-driven рантайм/рендерер для fractalUI.

Часть набора **fractalUI** — слоистой headless UI-библиотеки для быстрой сборки веб-интерфейсов.

## Установка

```bash
npm i @fractalui/runtime
```
