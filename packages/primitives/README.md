# @fractalui/primitives

Headless, доступные React-примитивы — ядро набора fractalUI.

Часть набора **fractalUI** — слоистой headless UI-библиотеки для быстрой сборки веб-интерфейсов.

## Установка

```bash
npm i @fractalui/primitives
```
